## 我的项目

### **OWCS Stats**

> *技术栈：Vue 3 / Element Plus / ECharts / Node.js / Express / Sequelize / MySQL*

我正在开发一个围绕《[守望先锋](https://ow.blizzard.cn/home.html)》电竞赛事数据的可视化平台 **OWCS Stats**。

它主要用于展示战队、选手、地图、英雄禁用、比赛结果等数据，并通过图表和数据面板让赛事信息更直观。目前在网易大神APP中进行内嵌，并向国服赛区OWCS官方赛事制作提供数据支持。

我也在尝试把 Agent 引入数据导入和结构化解析流程中，让赛事数据的整理过程更自动化。除此之外，针对守望先锋赛事的独立全维度数据抓取工具也在 ~~幻想~~ 规划中。
